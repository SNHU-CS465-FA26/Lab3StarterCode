POST /continue

POST method to submit an answer to the current question and receive the next question or a quiz complete message, discriminated by status property in the response (new with api/v21)

  • HTTP method: POST
  • URL: https://{host}:{port}/api/v21/continue
  • Authentication: none
Parameters

None.

Request Body (optional)

Content type: application/json

Field Type Required Notes
sessionID string Yes The sessionID obtained from the quiz selection step
questionID string Yes The ID of the current question being answered
choiceIndex integer Yes The indices (range 1..n) of the choices being submitted for the current question

Example:

{
  "sessionID": "20261015-00001",
  "questionID": "Q1",
  "choiceIndex": 2
}
Responses
Status Meaning
200 Answer accepted, return next question or quiz complete message
400 Missing session/question/answer information
404 session expired or does not exist

200 — Answer accepted, return next question or quiz complete message

Content type: application/json

Type: one of: continue | exit

Example:

[
  {
    "status": "in_progress",
    "question": "What is the airspeed velocity of an unladen swallow?",
    "choiceIndices": [
      1,
      2,
      3,
      4
    ],
    "choiceTexts": [
      "An African or European swallow?",
      "I don't know that!",
      "Winter or Summer?",
      "Morning or Evening?"
    ]
  }
]

400 — Missing session/question/answer information

Content type: application/json

Field Type Required Notes
errorCode string Yes Machine-readable error code.
message string Yes Human-readable explanation of the error.

Example:

{
  "errorCode": "MISSING_INFORMATION",
  "message": "Missing session/question/Answer information"
}

404 — session expired or does not exist

Content type: application/json

Field Type Required Notes
errorCode string Yes Machine-readable error code.
message string Yes Human-readable explanation of the error.

Example:

{
  "errorCode": "SESSION_TIMED_OUT",
  "message": "The session has timed out due to inactivity."
}
Example

Request:

curl -X POST "https://{host}:{port}/api/v21/continue" \
  -H "Content-Type: application/json" \
  -d '{"sessionID":"20261015-00001","questionID":"Q1","choiceIndex":2}'

Response 200:

[
  {
    "status": "in_progress",
